# KuCoin APK — Decompiled Recovery Backup

This private repository contains the files recovered from the uploaded `kucoin.apk` backup using apktool 2.7.0.

- Decompiled resources: `res/`
- Decoded Android XML resources are readable plain text.
- Smali output is under `smali/` and `smali_classes*/`.
- Native libraries and packaged assets are preserved under `lib/` and `assets/`.
- This is a decompiled recovery snapshot, not the original Gradle/Android Studio source project.
